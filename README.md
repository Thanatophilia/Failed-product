# SilentIME

开源的 Android 中文输入法，主打安静、隐私与轻快。

## 简介

SilentIME 是一个开源、无广告、不收集任何输入数据的 Android 输入法。

## 特点

- 🔒 **隐私**：不上传、不收集、不联网 —— 输入内容只保留在本机
- 🚀 **轻量**：启动快、占用少、内存友好
- 🚫 **无广告**：没有弹窗、推荐位、用户画像
- 🧩 **全开源**：GPLv3.0 授权，代码完全可审计
- 🀄 **中文友好**：拼音与手写输入
- 🎨 **可定制**：主题（深色 / 浅色）、按键布局、自定义词库

## 功能规划

- [ ] 中文拼音输入（含九键 / 全键盘）
- [ ] 手写输入（本地识别，支持离线模型）
- [ ] 记忆、联想、纠错
- [ ] 剪贴板同步、快捷短语
- [ ] 键盘高度与震动反馈调节
- [ ] 深色 / 浅色主题切换，支持自定义配色
- [ ] 完全离线运行，不申请网络权限

## 构建

```bash
git clone https://github.com/Thanatophilia/SilentIME.git
cd SilentIME
./gradlew assembleDebug
```
